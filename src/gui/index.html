About the .rdl format

ℹ .rdl (Resume Data Layout) is ResumeGenX's custom plain-text format — structured like a simple key-value file, readable in any text editor.
01
Create a plain text file and save it with the .rdl extension — e.g. my_resume.rdl
02
Write your data using KEY: value pairs. Separate sections with a blank line.
03
Multi-value fields use a pipe separator — val1 | val2 | val3

File structure example

# Personal Info
NAME: John Doe
EMAIL: john@email.com
PHONE: +91 99999 99999

# Skills
SKILLS: Python | React | Node.js

# Education
EDU_DEGREE: B.Tech Computer Science
EDU_YEAR: 2024

# Experience
EXP_TITLE: Software Intern
EXP_COMPANY: Acme Corp
EXP_PERIOD: 2023-05 to 2023-08

Common mistakes to avoid

⚠Do not rename a .txt to .rdl — the parser validates internal structure, not just the extension.
⚠Avoid < > & \ " ' inside values — these break LaTeX rendering on export.
✓
Keys must be UPPERCASE with underscores — e.g. EXP_TITLE
✓
Date format: YYYY-MM — e.g. 2023-06
✓
Sections separated by exactly one blank line.
✓
Save as UTF-8 encoding. Max size: 5 MB.
